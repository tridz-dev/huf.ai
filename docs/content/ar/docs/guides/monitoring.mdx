# المراقبة والتصحيح

تتبع أداء الوكيل، وحل المشكلات، وتحسين التكاليف، وتأكد من أن وكلاءك يعملون بفعالية.

## لوحة تحكم تشغيل الوكيل

### الوصول إلى عمليات التشغيل

**انتقل إلى:** Desk → Huf → Agent Run

**عرض جميع عمليات تشغيل الوكيل:**
- التصفية حسب الوكيل والتاريخ والحالة
- البحث حسب الطلب أو الاستجابة
- الترتيب حسب وقت الإنشاء والتكلفة والرموز
- تصدير البيانات للتحليل

## فهم تفاصيل التشغيل

### الطلب والاستجابة

**عرض السياق الكامل:**
- رؤية الطلب الدقيق المرسل إلى الوكيل
- مراجعة استجابة الوكيل الكاملة
- التحقق من تاريخ المحادثة المضمن
- التحقق من تعريفات الأدوات المرسلة

**يُستخدم من أجل:**
- فهم استدلال الوكيل
- تصحيح الاستجابات غير المتوقعة
- تحسين الطلبات
- تحسين التعليمات

### استدعاءات الأدوات

**رؤية كل استدعاء للأدوات:**
- الأدوات التي تم استدعاؤها
- المعاملات المرسلة إلى الأدوات
- النتائج المُرجعة من الأدوات
- ترتيب تنفيذ الأدوات

**يُستخدم من أجل:**
- التحقق من استخدام الأدوات
- تصحيح أعطال الأدوات
- تحسين استدعاءات الأدوات
- فهم سير عمل الوكيل

### استخدام الرموز

**تتبع الاستهلاك:**
- **رموز الإدخال:** الطلب + السجل + الأدوات
- **رموز الإخراج:** استجابة الوكيل
- **إجمالي الرموز:** مجموع الإدخال والإخراج
- **التكلفة:** محتسبة بناءً على تسعير النموذج

**يُستخدم من أجل:**
- تحسين التكلفة
- تحديد عمليات التشغيل المكلفة
- تخطيط الميزانيات
- مقارنة النماذج

### الأخطاء والأعطال

**تحديد المشكلات:**
- رسائل الخطأ
- آثار المكدس
- استدعاءات الأدوات الفاشلة
- مشكلات المهلة

**الأخطاء الشائعة:**
- الأداة غير موجودة
- الإذن مرفوض
- معاملات غير صالحة
- أخطاء النموذج
- حدود المعدل

## تتبع التكلفة

### فهم التكاليف

**عوامل التكلفة:**
- تسعير النموذج (يختلف حسب المزود)
- استخدام الرموز (إدخال + إخراج)
- تعريفات الأدوات (تُضاف إلى رموز الإدخال)
- سجل المحادثة (يضيف رموزًا)

**حساب التكلفة:**
```
Total Cost = (Input Tokens × Input Price) + (Output Tokens × Output Price)
```

### تحليل التكلفة

**تتبع عبر الوقت:**
- التكاليف اليومية لكل وكيل
- الاتجاهات الأسبوعية
- الإجماليات الشهرية
- متوسط التكلفة لكل تشغيل

**تحديد عمليات التشغيل المكلفة:**
- استخدام رموز مرتفع
- محادثات طويلة
- استدعاءات أدوات كثيرة
- نماذج مكلفة

## تصحيح المشكلات

### المشكلات الشائعة

**الوكيل لا يستجيب بشكل صحيح:**
- راجع الطلب في Agent Run
- تحقق من وضوح التعليمات
- تحقق من تعيينات الأدوات
- اختبر بطلبات أبسط

**الأداة غير مستخدمة:**
- تحقق من وصف الأداة
- تحقق من أن الأداة مُعينة
- راجع تعليمات الوكيل
- اختبر الأداة مباشرة

**معدلات خطأ مرتفعة:**
- راجع رسائل الخطأ
- تحقق من الأذونات
- تحقق من توفر الأدوات
- اختبر المكونات بشكل فردي

**سلوك غير متوقع:**
- راجع سجل المحادثة
- تحقق من نتائج الأدوات
- تحقق من التعليمات
- اختبر الحالات الحدية

### أدوات التصحيح

**استخدم هذه الأدوات:**

### عرض المحادثات

**انتقل إلى:** Desk → Huf → Agent Conversation

**رؤية المحادثات الكاملة:**
- جميع الرسائل المتبادلة
- استدعاءات الأدوات التي تم إجراؤها
- السياق المحافظ عليه
- معلومات الجلسة

### تحليل المحادثة

**حلل:**
- طول المحادثة
- عدد الدورات
- أنماط استخدام الأدوات
- رضا المستخدم
- نجاح الحل

**يُستخدم من أجل:**
- تحسين سلوك الوكيل
- فهم احتياجات المستخدمين
- تحسين سير العمل
- تحسين التدريب

## سجلات استدعاءات الأدوات

### عرض استدعاءات الأدوات

**في Agent Run:**
- رؤية جميع استدعاءات الأدوات
- المعاملات الممررة
- النتائج المُرجعة
- ترتيب التنفيذ
- الأخطاء إن وجدت

### تحليل استخدام الأدوات

**أسئلة للإجابة عليها:**
- هل يتم استخدام الأدوات بشكل صحيح؟
- هل يتم اختيار الأدوات المناسبة؟
- هل استدعاءات الأدوات فعالة؟
- هل هناك استدعاءات غير ضرورية؟

**التحسين:**
- تحسين أوصاف الأدوات
- تحسين تعليمات الوكيل
- إزالة الأدوات غير المستخدمة
- تحسين استعلامات الأدوات

## دليل استكشاف الأخطاء وإصلاحها

### الوكيل لا يعمل

**تحقق من:**
- حالة الوكيل (نشط؟)
- هل المشغل مفعّل؟
- هل الأذونات صحيحة؟
- هل التبعيات متوفرة؟

**الإصلاح:**
- فعّل الوكيل
- مكّن المشغل
- أصلح الأذونات
- ثبّت التبعيات

### معدل خطأ مرتفع

**تحقق من:**
- رسائل الخطأ
- توفر الأدوات
- مشاكل الأذونات
- مشاكل النموذج

**الإصلاح:**
- عالج الأسباب الجذرية
- أصلح الأدوات
- حدّث الأذونات
- غيّر النموذج إذا لزم الأمر

### استجابات غير متوقعة

**تحقق من:**
- وضوح التعليمات
- تعيينات الأدوات
- سجل المحادثة
- سلوك النموذج

**الإصلاح:**
- حسّن التعليمات
- اضبط الأدوات
- حدّد السجل
- اختبر نماذج مختلفة

### تكاليف مرتفعة

**تحقق من:**
- استخدام الرموز
- تسعير النموذج
- طول المحادثة
- تعريفات الأدوات

**الإصلاح:**
- استخدم نماذج أرخص
- حدّد السجل
- حسّن الطلبات
- قلّل عدد الأدوات
