# التثبيت

تطبيق هف (Huf) هو تطبيق مبني على إطار عمل فرابيه (Frappe). يغطي هذا الدليل كيفية تثبيته على موقع فرابيه الخاص بك، سواء كنت تستخدم فرابيه بنش (Frappe Bench - استضافة ذاتية/محلية) أو فرابيه كلاود (Frappe Cloud - استضافة مدارة).

## المتطلبات الأساسية

قبل التثبيت، يجب أن يكون لديك موقع فرابيه يعمل بشكل صحيح. إذا كنت جديدًا على نظام فرابيه أو لم يكن لديك موقع بعد، فتفضل بزيارة [وثائق إطار عمل فرابيه](https://frappeframework.com/docs/user/en/installation) للبدء في إعداد فرابيه أولاً.

يجب أن تتوفر لديك المتطلبات التالية:
* موقع فرابيه (بنش Bench أو كلاود Cloud)
* إمكانية الوصول إلى سطر الأوامر (Terminal/console) لموقعك
* إصدار بايثون Python 3.8+ (عادةً ما يكون مثبتًا تلقائيًا مع فرابيه)

**هل أنت جديد على فرابيه بنش (Frappe Bench)؟**
البنش (Bench) هو أداة سطر الأوامر لإدارة تطبيقات ومواقع فرابيه. يمكنك التفكير فيه كمدير حزم لـ فرابيه — فهو يتعامل مع عمليات التثبيت والتحديثات وإدارة المواقع والتطبيقات المتعددة.

## التثبيت على فرابيه بنش (Frappe Bench)

للإعدادات ذاتية الاستضافة أو المحلية باستخدام البنش (Bench):

### 1. الانتقال إلى مجلد البنش (Bench Directory)

```bash
cd /path/to/your/frappe-bench
```

استبدل `/path/to/your/frappe-bench` بالمسار الفعلي لمجلد البنش لديك (على سبيل المثال: `~/frappe-bench`).

### 2. جلب التطبيق (Get the App)

قم بتحميل تطبيق Huf من GitHub:

```bash
bench get-app https://github.com/tridz-dev/agent_flo.git
```

سيقوم هذا الأمر باستنساخ تطبيق Huf داخل مجلد `apps/`.

### 3. التثبيت على موقعك (Install on Your Site)

قم بتثبيت Huf على موقعك الفعلي (استبدل `sitename` باسم موقعك الحالي):

```bash
bench --site sitename install-app huf
```

### 4. إعداد المتطلبات والتبعيات

يتطلب تطبيق Huf مكتبة LiteLLM وحزم بايثون أخرى. قم بتثبيتها عبر:

```bash
bench setup requirements
```

### 5. إعادة التشغيل (Restart)

```bash
bench restart
```

### 6. التحقق من التثبيت

سجل الدخول إلى موقع فرابيه الخاص بك. انقر على **مبدل التطبيقات (App Switcher)** (أيقونة الشبكة في أعلى اليمين) وابحث عن **Huf** أو **AgentFlo**. انقر عليه للدخول إلى مساحة عمل Huf.

## التثبيت على فرابيه كلاود (Frappe Cloud)

فرابيه كلاود (Frappe Cloud) هي خدمة استضافة مدارة لنظام فرابيه. يمكنك تثبيت Huf باستخدام واجهة الويب أو عبر أوامر وحدة التحكم (Console).

### الطريقة الأولى: باستخدام واجهة الويب (موصى به)

توفر فرابيه كلاود واجهة مستخدم سهلة لإضافة التطبيقات إلى موقعك.

#### 1. الوصول إلى متجر التطبيقات (Marketplace)

سجل الدخول إلى [frappecloud.com](https://frappecloud.com)، وانتقل إلى موقعك، وافتح قسم **المتجر (Marketplace)** أو **التطبيقات (Apps)**. انقر على **إضافة تطبيق من المتجر (Add Marketplace App)**.

![Add Marketplace App interface showing available apps](/images/add-marketplace-app.png)

يعرض المتجر التطبيقات المتاحة للتثبيت. يمكنك البحث عن التطبيقات أو إضافتها مباشرة من موقع GitHub.

#### 2. الإضافة من GitHub

انقر على زر **إضافة من GitHub (Add from GitHub)** (الموجود في الزاوية العلوية اليمنى من واجهة المتجر).

![Add app from GitHub modal](/images/add-from-github.png)

في النافذة التي تظهر:
1. اختر تبويب **"تطبيق GitHub عام" (Public GitHub App)**.
2. أدخل الرابط التالي: `https://github.com/tridz-dev/agent_flo`
3. اختر الفرع (branch) الذي ترغب في تثبيته.
4. سيتعرف النظام تلقائيًا على التطبيق باسم "Huf (huf)".
5. انقر على **إضافة التطبيق (Add App)** لبدء التثبيت.

سيتم تثبيت التطبيق وتكوينه تلقائيًا على موقعك.

#### 3. التحقق

بعد اكتمال عملية التثبيت، قم بتحديث الصفحة في موقعك، وافتح **مبدل التطبيقات (App Switcher)**، ثم انقر على **Huf** أو **AgentFlo**.

### الطريقة الثانية: باستخدام أوامر وحدة التحكم (Console Commands)

بدلاً من واجهة الويب، يمكنك تثبيت Huf باستخدام الأوامر:

#### 1. فتح وحدة التحكم (Console)

سجل الدخول إلى [frappecloud.com](https://frappecloud.com)، انتقل إلى موقعك، وافتح **وحدة التحكم (Console)** (أيقونة الطرفية/Terminal).

#### 2. التثبيت

نفّذ الأوامر التالية في وحدة التحكم:

```bash
bench get-app https://github.com/tridz-dev/huf.git
bench --site $CI_COMMIT_REF_NAME install-app huf
bench setup requirements
bench restart
```

> المتغير `$CI_COMMIT_REF_NAME` يتم تعيينه تلقائيًا ليمثل اسم موقعك على فرابيه كلاود.

#### 3. التحقق

قم بتحديث موقعك، وافتح **مبدل التطبيقات**، ثم انقر على **Huf**.

## استكشاف الأخطاء وإصلاحها

**ظهور خطأ "Command not found: bench"**
* أداة Bench غير مثبتة أو لم يتم إضافتها إلى مسار النظام (PATH).
* يرجى مراجعة [وثائق تثبيت فرابيه](https://frappeframework.com/docs/user/en/installation).

**ظهور خطأ "App not found" أو فشل التثبيت**
* تأكد من أنك تعمل داخل مجلد البنش الصحيح.
* تأكد من صحة اسم موقعك عبر الأمر: `bench --site sitename list-apps`
* تحقق من اتصال الإنترنت (لتحميل الحزم من GitHub).
* جرب تنفيذ الأمر `bench update` أولاً للتأكد من تحديث البنش.

**التبعيات (Dependencies) لا تثبت**
* تحقق من إصدار بايثون (بحد أدنى 3.8) عبر الأمر: `python3 --version`
* تأكد من أن مدير الحزم pip متاح.
* لبيئات التطوير، جرب الأمر: `bench setup requirements --dev`

**أخطاء LiteLLM**
* يتطلب Huf مكتبة LiteLLM للاتصال بمزودي الخدمة.
* أعد تشغيل الأمر `bench setup requirements`.
* أعد تشغيل خادم الموقع عبر `bench restart`.
* تحقق من السجلات: افتح الكونسول عبر `bench --site sitename console` ثم نفّذ `import litellm` للتحقق من سلامة استيراد المكتبة.
