    <span className="huf-ps-label">Solution</span>
    Agents analyze leads, score them, and route to appropriate sales reps.
  </div>

### Capabilities

The agent evaluates lead quality, enriches data, assigns reps, and schedules follow-ups.

<div className="huf-cap-grid">
  <div className="huf-cap-cell"><span className="huf-cap-term">Lead Scoring</span>Evaluate leads based on multiple criteria</div>
  <div className="huf-cap-cell"><span className="huf-cap-term">Data Enrichment</span>Look up company info, social profiles</div>
  <div className="huf-cap-cell"><span className="huf-cap-term">Assignment Logic</span>Assign to best sales rep based on territory, workload, expertise</div>
  <div className="huf-cap-cell"><span className="huf-cap-term">Follow-up Scheduling</span>Set appropriate follow-up dates</div>
  <div className="huf-cap-cell"><span className="huf-cap-term">Qualification</span>Determine if lead meets criteria</div>
</div>

### Agent Configuration

Configure the agent with lead, territory, and task tools plus scoring instructions.

<ConfigPanel title="Agent Configuration">
  <ConfigField label="Tools Required" value="Get Document (Lead, Customer, Territory) · Get List (Sales Person, existing leads) · Create Document (Lead, Task) · Update Document (Lead assignment) · Custom Tools (for scoring algorithm)" />
  <AgentPrompt title="Lead Qualifier Agent">
    When a new lead is created:
    1. Score the lead based on:
       - Company size (from company_name lookup)
       - Industry match with our ideal customer profile
       - Source quality (referral > website > cold)
       - Budget indicators in description
    2. Assign to sales rep based on:
       - Territory match
       - Current workload (fewer active leads = higher priority)
       - Industry expertise
    3. Set follow-up date:
       - Hot leads: Same day
       - Warm leads: Next business day
       - Cold leads: Next week
    4. Add internal notes with scoring rationale
    5. Notify assigned sales rep
  </AgentPrompt>
  <div className="huf-trigger-badge">After Insert on Lead DocType</div>
</ConfigPanel>

### Benefits

Faster, more consistent lead handling improves conversion and rep productivity.

  <div className="huf-benefit-cell"><span className="huf-benefit-label">Faster Response</span>Hot leads get immediate attention</div>

<ConfigPanel title="Agent Configuration">
  <ConfigField label="Tools Required" value="Get List (with dynamic filters) · Get Document (for details) · Custom Tools (for report formatting) · HTTP Request (for exporting to Excel/PDF)" />
  <AgentPrompt title="Report Generator Agent">

    1. Understand what data they want (sales, inventory, customers, etc.)
