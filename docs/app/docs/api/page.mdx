# API Overview

HUF exposes its functionality through standard **Frappe whitelisted REST endpoints**. Any Python function decorated with `@frappe.whitelist()` is automatically available at a predictable URL. No custom routing or API gateway is required.

## Base URL Pattern

```
POST /api/method/<dotted.python.path>
```

All endpoints accept `application/x-www-form-urlencoded` or `application/json` POST bodies, and respond with JSON.

**Examples:**
```
POST /api/method/huf.ai.agent_integration.run_agent_sync
POST /api/method/huf.ai.chat_api.run_agent_sync_chat
GET  /api/method/huf.ai.agent_chat.get_history?conversation_id=CONV-001
```

## Authentication

Frappe supports multiple authentication schemes:

### Session Cookie (Browser)

Logging into the Frappe desk sets a `sid` session cookie. API requests from the same browser session are automatically authenticated.

### API Key + Secret (Programmatic)

Generate an API Key and Secret for a Frappe user:
1. Open the User document in Frappe desk.
2. Click **Generate Keys** in the API Access section.

Pass them as request headers:
```http
Authorization: token <api_key>:<api_secret>
```

```bash
curl -X POST https://your-site.example.com/api/method/huf.ai.agent_integration.run_agent_sync \
  -H "Authorization: token abc123:xyz789" \
  -H "Content-Type: application/json" \
  -d '{"agent_name": "My Agent", "prompt": "Hello"}'
```

### Guest Access

Some HUF endpoints accept unauthenticated requests when the Agent has `allow_guest = 1`. These endpoints are decorated with `@frappe.whitelist(allow_guest=True)`. No authentication header is required.

See the [Running Agents via API](./run-agent) page for guest-access examples.

## Guest Access

Mark an agent with `allow_guest = 1` to allow unauthenticated API calls:

```bash
curl -X POST https://your-site.example.com/api/method/huf.ai.agent_integration.run_agent_sync \
  -H "Content-Type: application/json" \
  -d '{"agent_name": "Public FAQ Bot", "prompt": "What are your hours?"}'
```

> [!CAUTION]
> Guest agents have mutating tools blocked by `PermissionAwareToolRegistry` unless the specific tool has `allowed_for_guest = 1`. Read-only access is safe; write access requires explicit configuration. See [Permissions & Security](/docs/permissions) for details.

## Rate Limiting

HUF endpoints use the standard Frappe rate limiting system. Default limits apply per IP and per user. Configure rate limits in the Frappe site config:

```python
# site_config.json
{
  "rate_limit": {
    "limit": 1000,
    "window": 3600
  }
}
```

## Error Responses

All errors follow the Frappe error format:

```json
{
  "exc_type": "ValidationError",
  "exc": "...",
  "_server_messages": "[{\"message\": \"Agent Name is required\"}]"
}
```

HTTP status codes: `200 OK`, `403 Forbidden`, `404 Not Found`, `417 Expectation Failed` (Frappe validation errors).
