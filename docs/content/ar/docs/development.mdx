# التطوير

هذا الدليل موجه للمطورين الذين يريدون توسيع وظائف Huf، أو إنشاء تكاملات مخصصة، أو المساهمة في المشروع.

## المتطلبات الأساسية

**المعرفة المطلوبة:**
- خبرة في تطوير إطار عمل Frappe
- برمجة Python
- فهم أنواع المستندات (DocTypes) والخطافات (hooks) والصلاحيات
- معرفة أساسية بالنماذج اللغوية الكبيرة (LLMs) والوكلاء الذكيين

**إذا كنت جديدًا على Frappe:** ابدأ بـ [توثيق إطار عمل Frappe](https://frappeframework.com/docs) قبل توسيع Huf.

## هيكل المشروع

يتبع Huf هيكل تطبيق Frappe القياسي:

```
huf/
├── huf/                    # Main Python module
│   ├── doctype/                 # DocType definitions
│   │   ├── agent/
│   │   ├── ai_provider/
│   │   ├── ai_model/
│   │   └── agent_tool_function/
│   └── ai/                      # Core AI integration
│       ├── agent_integration.py
│       ├── conversation_manager.py
│       ├── tool_discovery.py    # @agent_tool decorator
│       └── providers/
│           └── litellm.py
├── hooks.py
├── install.py
└── www/                         # Web assets
```

## نقاط التوسيع

### 1. نشر الأدوات من تطبيقك

أسهل طريقة لتوسيع Huf هي نشر الأدوات من تطبيق Frappe الخاص بك.

**استخدم المزيِّن `@agent_tool`:**

```python
from huf.ai.tool_discovery import agent_tool

@agent_tool
def my_custom_tool(param1: str, param2: int) -> dict:
    """
    Description of what this tool does.
    
    Args:
        param1: Description of param1
        param2: Description of param2
        
    Returns:
        dict: Result data
    """
    # Your implementation
    return {"result": "data"}
```

**انظر:** [نشر الأدوات](/docs/tools/publishing) للحصول على دليل كامل.

### 2. دوال الأدوات المخصصة

أنشئ الأدوات يدويًا عبر نوع المستند Agent Tool Function:

1. اكتب دالة Python في تطبيقك
2. أنشئ سجلًا لـ Agent Tool Function
3. اربط الدالة عبر مسار الدالة (Function Path)
4. أسنِدها إلى الوكلاء

**انظر:** [إنشاء أدوات مخصصة](/docs/tools/custom) للمزيد من التفاصيل.

### 3. خطافات Frappe

وسّع Huf باستخدام نظام الخطافات في Frappe:

**في ملف `hooks.py` الخاص بتطبيقك:**

```python
# Before agent runs
agent_before_run = "my_app.hooks.validate_agent_config"

# After agent runs
agent_after_run = "my_app.hooks.log_custom_metrics"

# Custom tool execution
agent_tool_call = "my_app.hooks.handle_custom_tool"
```

**مثال على تنفيذ الخطاف:**

```python
# my_app/hooks.py
def validate_agent_config(agent, prompt, context):
    """Validate agent configuration before run."""
    if agent.name == "Critical Agent":
        # Add custom validation
        if not agent.custom_field:
            frappe.throw("Custom field required for critical agents")
```

### 4. موفّرون مخصصون

على الرغم من أن Huf يستخدم LiteLLM لمعظم الموفّرين، يمكنك إضافة تطبيقات مخصصة للموفّرين:

**أنشئ وحدة موفّر:**

```python
# huf/ai/providers/custom.py
async def run(agent, enhanced_prompt, provider, model, context=None):
    """Custom provider implementation."""
    # Your custom logic
    response = await your_custom_api_call(enhanced_prompt)
    return {
        "response": response.text,
        "tokens": response.tokens_used,
        "cost": response.cost
    }
```

**سجّل في التوجيه:**

```python
# huf/ai/run.py
if provider.name == "Custom Provider":
    from huf.ai.providers import custom
    return await custom.run(...)
```

### 5. تخصيصات أنواع المستندات (DocTypes)

وسّع أنواع مستندات Huf باستخدام نظام التخصيص في Frappe:

**أضف حقولًا مخصصة:**
- انتقل إلى Customize Form
- أضف حقولًا إلى Agent وAI Provider وغيرها
- استخدمها في الخطافات والنصوص البرمجية

**أضف نصوصًا برمجية مخصصة:**
- نصوص برمجية للعميل للتحكم في سلوك واجهة المستخدم
- نصوص برمجية للخادم للتحقق من الصحة
- تنسيقات الطباعة للتقارير

### 6. توسيعات واجهة البرمجة (API)

أنشئ نقاط نهاية API مخصصة تستخدم Huf:

```python
# my_app/api/agent_extensions.py
import frappe
from huf.ai.agent_integration import AgentManager

@frappe.whitelist()
def custom_agent_workflow(data):
    """Custom workflow using Huf agents."""
    # Get agent
    manager = AgentManager("My Agent")
    
    # Run agent
    result = manager.run_sync(data["prompt"])
    
    # Custom processing
    processed = your_custom_logic(result)
    
    return processed
```

## المكوّنات الأساسية

### تكامل الوكيل (`agent_integration.py`)

**فئة `AgentManager`:**
- تحضير الوكلاء للتنفيذ
- إدارة سياق المحادثة
- التعامل مع تسلسل الأدوات
- التوجيه إلى الموفّرين

**الدوال الرئيسية:**
- `prepare_agent()`: تحميل إعدادات الوكيل
- `run_sync()`: تنفيذ الوكيل بشكل متزامن
- `get_conversation()`: استرجاع سجل المحادثة

### مدير المحادثة (`conversation_manager.py`)

**يتعامل مع:**
- استمرارية المحادثة
- سجل الرسائل
- إدارة الجلسات
- بناء السياق

**الدوال الرئيسية:**
- `get_or_create_conversation()`: الحصول على جلسة المحادثة أو إنشاؤها
- `add_message()`: إضافة رسالة إلى المحادثة
- `get_history()`: استرجاع سجل المحادثة

### اكتشاف الأدوات (`tool_discovery.py`)

**المزيِّن `@agent_tool`:**
- فحص التطبيقات بحثًا عن الدوال المزيّنة
- إنشاء سجلات Agent Tool Function
- المزامنة عند تثبيت/ترحيل التطبيق

**الدوال الرئيسية:**
- `agent_tool()`: دالة المزيِّن
- `discover_tools()`: فحص وتسجيل الأدوات
- `sync_tools()`: تحديث سجلات الأدوات

### نظام الموفّر (`providers/litellm.py`)

**تكامل LiteLLM:**
- واجهة موحدة لأكثر من 100 موفّر
- منطق إعادة المحاولة التلقائي
- تتبع التكلفة
- توحيد أسماء النماذج

**لماذا LiteLLM:**
- يدعم أكثر من 100 موفّر
- معالجة الأخطاء مدمجة
- حساب التكلفة
- توحيد أسماء النماذج

## أنماط التوسيع الشائعة

### النمط 1: التحقق المخصص

**حالة الاستخدام:** التحقق من إعدادات الوكيل قبل التشغيل

```python
# hooks.py
agent_before_run = "my_app.hooks.validate_agent"

# hooks.py implementation
def validate_agent(agent, prompt, context):
    if agent.custom_field == "restricted":
        # Check permissions
        if not frappe.has_permission("Custom DocType", "read"):
            frappe.throw("Permission denied")
```

### النمط 2: المقاييس المخصصة

**حالة الاستخدام:** تتبع مقاييس مخصصة لتشغيلات الوكيل

```python
# hooks.py
agent_after_run = "my_app.hooks.track_metrics"

def track_metrics(agent, run_result, context):
    frappe.get_doc({
        "doctype": "Custom Metric",
        "agent": agent.name,
        "tokens": run_result.get("tokens_used", 0),
        "cost": run_result.get("cost", 0),
        "success": run_result.get("status") == "success"
    }).insert()
```

### النمط 3: غلاف الأداة

**حالة الاستخدام:** إضافة التسجيل أو التحقق إلى استدعاءات الأدوات

```python
# hooks.py
agent_tool_call = "my_app.hooks.wrap_tool_call"

def wrap_tool_call(tool_name, params, context):
    # Log tool call
    frappe.logger().info(f"Tool called: {tool_name}")
    
    # Add custom validation
    if tool_name == "sensitive_tool":
        validate_sensitive_access()
    
    # Continue with normal execution
    return None  # Return None to proceed normally
```
